# 《留灯》原型 0.1（微信小游戏工程）

2026-11-18 · Kira 搭 · 点子卡第 1 批「卡 2 · 《云养》最小版」的**第一版**：单机，朋友是两个按作息自己来的假人（小C、阿树），只测照顾宠物的手感、房间好不好看、「一个人照顾不过来」的紧张感。

## 怎么打开

| 想在哪看 | 怎么做 |
| --- | --- |
| 电脑浏览器 | 双击 `preview.html` |
| 手机 | 推到 GitHub Pages 后打开 `index.html`（和 preview.html 一模一样） |

## 怎么玩

- 三个人合住一间小屋，养一只橘白猫「灯芯」。左边角落是小C（夜猫子，每晚 23:10 来盖被子、13:20 来摸摸它），右边是阿树（早起，07:40 喂饭洗澡、18:30 再喂一次），窗下是你的角落。
- 下面四条：**饱 / 困 / 心 / 净**，会按节奏往下掉。四个按钮：
  - **喂**：点一下，猫粮倒进碗里，它跑过去吃。
  - **摸头**：手指在它身上来回划，划够一圈就算摸完（它闹脾气时要划两倍）。
  - **盖被**：它困了才肯睡，被子从上面落下来，盖的是谁的被子颜色就是谁的。
  - **洗**：点一下拿起海绵，在它身上来回擦。
- 每件事花 1 点**精力**（上面的小灯火），最多 3 点，3 小时回 1 点。**一个人一天最多做 8 件，它一天要 14 件左右**——得靠朋友。
- 朋友会**缺席**（加班、睡过头、出远门）。上面会跳出「小C 没来」：你可以「我来」（花自己的精力），也可以「代盖被（看广告）」。替了她，记录里写「你替小C 给它盖了被子」，她下次来会回你一颗爱心。
- 点朋友的角落：敲门 / 留爱心（今天留过爱心，她缺席的机会减半）。朋友留在角落的爱心，点一下收下，回 1 点精力。
- 点你自己的角落：摆一件家具（懒人沙发、小书架、小鱼缸、毛线篮；限定「星星帐篷」看广告解锁）。
- 房间里的痕迹：碗和按钮上的小头像 = 最后是谁做的；底部一行 = 最新一条「小C 昨晚 23:10 给它盖了被子」，点开看全部。
- 右下「叫朋友」：展示会发出去的分享卡（「它饿了，快回来喂它」等，跟着它最缺的东西变），不会真的发。
- 右上「快进3h」是调试按钮：一下过 3 小时，弹出「这 3 小时里发生了什么」。

## 稍微难一点：后果

| 没照顾好 | 会怎样 |
| --- | --- |
| 任何一项低于 25 | **闹脾气**：背过身，头上一团乱线，摸要摸两倍久 |
| 某项见底 6 小时 | **生病**：躺着、脸红、体温计，需求掉得更快；「请医生（看广告）」马上好，不然要全部养到 50 以上连续 10 小时 |
| 心情低于 22 | **跑去最近照顾它的朋友角落睡**（Widgetable 的「打小报告」） |
| 困到底没人盖被子 | **睡在地板上**，回得慢，还可能着凉生病；又困又饿就睡不着 |
| 谁 20 小时没来 | 它**望着那个人的角落**，头上冒泡泡是她的脸；你自己很久没来，回来时它扑过来 |

## 能调的数（都在 `js/config.js`）

| 想改什么 | 改哪 |
| --- | --- |
| 时间流速（现在真实 1 分钟 = 游戏 10 分钟；改成 1 就是真实时间） | `time.gamePerRealMin` |
| 快进一次多久 | `time.fastForwardMin` |
| 四项掉多快 | `needs.decayPerHour` |
| 每个动作回多少、摸多久 | `acts` |
| 精力上限、多久回一点 | `energy` |
| 闹脾气 / 生病 / 跑去角落 / 想念的门槛 | `sulk` `sick` `corner` `miss` |
| 朋友的名字、作息、缺席机会、出远门机会、借口 | `friends` |
| 替朋友的窗口 | `cover.windowMin` |
| 假广告多长 | `fakeAdSec` |
| 家具、限定家具 | `furniture` |
| 分享卡文案 | `share.lines` |

## 测试结果（2026-11-18）

机器人（真点按钮、真在猫身上划，用快进各过三天，同一个随机种子）：

| 玩家 | 平均满足 | 闹脾气 | 生病 | 在朋友角落 |
| --- | --- | --- | --- | --- |
| 懒人：一天来两次，只喂一下 | 22 | 88% | 62% | 80% |
| 勤快人：三小时一次，替朋友，病了请医生 | 75 | 0% | 0% | 0% |

规则层 300 局 × 三天（`test/balance.js`）：

| 玩家 | 平均满足 | 闹脾气 | 生病时间 | 三天里病过 |
| --- | --- | --- | --- | --- |
| 不来 | 18 | 89% | 71% | 100% |
| 一天一次 | 22 | 89% | 71% | 100% |
| 一天两次 | 38 | 73% | 41% | 93% |
| 一天三次（替朋友） | 58 | 31% | 6% | 22% |
| 勤快（三小时一次，晚上睡觉，不看广告） | 69 | 8% | 1% | 2% |
| 勤快但不替朋友 | 65 | 14% | 1% | 3% |
| 勤快 + 看广告 | 72 | 4% | 0% | 0% |

一天来两次就会病——这是「稍微难一点」的代价，**要不要再松一点请 Cc 定**（松：把 `sick.neglectMin` 从 360 调大，或把 `needs.decayPerHour` 调小）。

机器人另外核对了：一次点击只算一次；饱了再点不花精力；没精力时提示；留爱心；看广告解锁限定家具；分享卡只展示；没有报错。

## 还没做 / 已知问题

- 朋友是假的：作息固定，不会因为你做了什么改变作息（只有「留爱心」会让她少缺席一点）。
- 一天来两次的玩家三天里几乎都会病一次，可能偏难，待 Cc 试玩定。
- 真机帧率、iPhone 上的声音没实测（浏览器里机器人测的）。
- 横幅里有小字；痕迹记录只显示最近 14 条，不能翻页。
- 家具只是摆设，猫不会去坐。
- 没有真广告、真分享、宠物起名（起名要接内容安全）。

## 第二版要接什么

依据：`想法/调研_微信好友共养与模拟社区_1.0.md`。

1. **微信云开发**当后端（新用户免费 6 个月）：一间屋子一条记录，存需求值、每个人的最后来访、痕迹记录、家具。规则层 `js/sim.js` 原样搬到云函数里跑（按时间补算，跟现在的「离线补算」一样），客户端只发「我做了什么」。
2. **分享卡入住**：好友数据存不下共养宠物，所以用分享卡带房间号——`platform.share` 换成 `wx.shareAppMessage({ query: 'room=xxx' })`，好友点开就加入那间屋、占一个角落；`config.share.realShare` 打开。分享卡文案已经按「它最缺什么」写好。
3. 两个假朋友换成真人：作息和缺席不再随机，「替她」「她回谢」都变成真的人和人。假朋友的逻辑可以留着，当「朋友还没来」时的陪伴。
4. 提醒：订阅消息「它饿了」需要用户授权，先只用分享卡拉回来。
5. 仍然不开自由文字（只有敲门、留爱心这类预设动作），避开个人主体做社交的审核风险；要起名再接内容安全接口。
6. 过关标准（点子卡）：试玩小群两两配对，三天里每天都回来的人过半算活。
